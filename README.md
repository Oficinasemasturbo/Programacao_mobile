#AppScholar 

##Ele é um site/APP criado com o intuito de simular um aplicativo que mostra e permite alterações de um Banco de Dados de uma escola, onde nele contém Alunos, Matérias, Matrículas, etc.

##Funcionalidades

-Poder editar as Informações do Banco;

-Visualizar os Dados de forma simples e direta;

-Adicionar ou excluir Dados;

##Tecnologias Utilizadas

-Snack.Expo.Dev (Utilizado para fazer o teste e o código);

-Xampp (Para montar e hospedar o Banco de Dados);

-Canva (Utilizado para montar a logo);

##Estrutura do Projeto

-A primeira pasta é a das API's, nela contém os php's responsáveis pelo ligamento com o Banco de Dados, assim, fazendo com que as Funcionalidades funcionem;

-A segunda pasta é a BD, nela contém, o Dicionário de Dados, na versão PDF e na versão do Excel, um modelo visual do Banco montado, utilizando o BrModelo e o próprio Banco de Dados completo;

-Na terceira (e última) pasta, tem a Logo do AppScholar e o código responsável por suas telas;

##Como Executar

-Você deve baixar toda a pasta, assim que baixado, coloque o Banco de Dados no Xampp, coloque as API's e o Código das telas dentro do Snack e a logo dentro da pasta Assets (que já existe dentro do Snack); (Caso queira ver sobre as tabelas do Banco, acesse o Dicionário de Dados, lá tem cada tabela detalhada)
